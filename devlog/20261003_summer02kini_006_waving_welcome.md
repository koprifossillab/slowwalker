# 완보동물이 먼저 인사한다

2026-10-03 · `codex/waving-tardigrade-loader` · summer02kini

## 왜 짧은 인사를 넣었나

처음에는 지도를 바로 열기로 했지만, 사용자가 Wegener's Dream처럼 움직이는 시작 화면을
요청했다. 설명을 읽어야 하는 도입부 대신, 웃는 완보동물이 앞다리로 인사하는 짧은 장면을
만들었다. 종이색 바탕과 갈색 글씨는 기존 지도의 분위기와 이어진다.

캐릭터는 네 쌍의 다리와 작은 발톱을 가진 새로운 SVG 그림이다. 한쪽 앞다리의 반복 인사,
몸의 가벼운 움직임, 눈 깜박임은 CSS로 표현한다. 다른 프로그램의 그림이나 코드를 복사하지
않고 저장소의 파일만으로 보여 주므로, 외부 영상이나 애니메이션 서비스의 로딩을 기다리지 않는다.

## 지도로 가는 길을 막지 않는다

보통은 약 2.8초의 인사와 채집 기록 요청이 끝나면 지도로 넘어간다. 원격 배경지도 타일 전체가
도착할 때까지 기다리지는 않는다. `지도로 바로가기`와 Escape로 바로 닫을 수 있고, 스크립트나
연결이 늦어지면 8초의 제한 뒤 지도를 연다. 실제 진척률이 없는 백분율은 표시하지 않는다.

`인사 더 보기`는 사용자가 직접 자동 전환을 멈추는 선택이다. 지도 아래의 `인사 다시 보기`도
같은 장면을 열며, 이때는 사용자가 닫을 때까지 인사를 계속한다. 움직임 줄이기 설정에서는
캐릭터를 정지시키고 최소 대기와 사라지는 효과를 생략한다.

인사 화면은 기본 HTML에서 숨겨져 있으며, 스크립트가 준비되면 열린다. 표시 중에는 뒤의 지도
조작을 잠그고 키보드 초점을 두 버튼 안에 둔다. 닫기가 여러 번 일어나도 타이머와 지도 잠금은
한 번만 정리하며, 닫힘 처리는 애니메이션 종료 이벤트에만 의존하지 않는다.

## 검증

기존 Django 검사 38개와 정적 파일 수집을 통과했다. 제어 스크립트는 격리된 타이머 검사에서
자동 종료·최대 대기·건너뛰기·다시 보기·동작 줄이기·초점 복원을 확인했다. 브라우저에서도
자동 지도 진입, 더 보기, 다시 보기, Tab 순환과 Escape 종료, 390×844 화면 배치를 확인했다.
앞다리의 변환 값이 시간에 따라 바뀌며 인사가 반복되는 것을 확인했다.
